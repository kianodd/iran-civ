# ایران؛ نقشهٔ تمدن

ایران به سبک نقشهٔ Civilization — ۳۱ استان با داده‌های واقعی. ایده‌ای به سبک پروژهٔ [usaciv کارپتی](https://karpathy.ai/usaciv) که آمریکا را با داده‌های واقعی به نقشهٔ Civilization تبدیل کرد؛ اینجا همان کار برای ایران.

**زنده:** https://kianodd.github.io/iran-civ/

## چی دارد

- نقشهٔ SVG واقعی ۳۱ استان (مرز GADM ۴٫۱، ساده‌شده برای وب)
- لنزها: جمعیت، تراکم جمعیت، اقتصاد، صنعت، کشاورزی، اقلیم، گردشگری
- پنل هر استان: جمعیت و مساحت (سرشماری ۱۳۹۵)، «محلهٔ تمدن» بر پایهٔ تخصص واقعی استان (نفت خوزستان، فولاد اصفهان، مس کرمان، برنج گیلان، زعفران خراسان جنوبی…)، شهرهای مهم، شاخص‌های تقریبی
- ۳۰ شهر بزرگ با جمعیت و تخصص
- جست‌وجوی استان/شهر، فهرست استان‌ها و شهرها با مرتب‌سازی، تم روشن/تیره
- PWA کاملاً آفلاین: manifest + service worker، بدون هیچ وابستگی خارجی (فونت وزیرمتن داخلی)

## داده‌ها و دقت

- جمعیت و مساحت: سرشماری ۱۳۹۵ مرکز آمار ایران (via citypopulation.de) — اعداد دقیق همان سرشماری‌اند، جمعیت امروز بیشتر است.
- شاخص‌های اقتصاد/صنعت/کشاورزی/گردشگری: تقریبی ۰ تا ۱۰۰، نه آمار رسمی.
- مرزها ساده‌شده (۰٫۰۲ درجه) و مختصات شهرها تقریبی‌اند — برای مرور کلی، نه نقشه‌برداری.

## توسعه

```bash
python3 tools/build-paths.py   # GeoJSON -> js/paths.js
node tests/smoke.test.js       # تست دود: ۳۱ استان، لنزها، نسخه
python3 push.py                # انتشار روی GitHub Pages + تایید SHA
python3 tools/verify-live.py   # تایید فایل‌های زنده
```

Vanilla JS + SVG، بدون build step.
